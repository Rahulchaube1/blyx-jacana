# Jacana starter

Compare a crude event rate with a directly standardized rate.

Open the extracted folder in VS Code. With Blyx 0.2.1 and its host toolchain installed, choose **Terminal → Run Task → Run Jacana** or run the following command in this directory.

```sh
blyxc native-run main.blyx
```

Expected output

```text
0.75
0.5
-0.25
8
```

The vendor directory contains the framework source for 0.1.1 and its license texts. [Read the API guide](https://www.blyx-lang.space/packages/jacana) · [View the release](https://github.com/Rahulchaube1/blyx-jacana/releases/tag/v0.1.1)
